# Pretest-Protokoll (09:15 – 10:15, letzte 15 Minuten)

Der Pretest prüft nicht die Antworten, sondern **ob der Leitfaden in 30 Minuten funktioniert**.
Eine Person aus dem Team spielt den Probanden und antwortet realistisch ausführlich –
nicht hilfsbereit kurz.

## Ablauf

- [ ] Stoppuhr, Blöcke einzeln messen
- [ ] Interviewer spielt es durch, ohne zu kürzen
- [ ] Rest des Teams notiert Probleme in der Tabelle unten

## Timing

| Block | Soll | Ist | Massnahme |
|---|---|---|---|
| 1 Ankommen | 3' | | |
| 2 Event & Kaufkontext | 6' | | |
| 3 Preiswahrnehmung | 5' | | |
| 4 Erfahrung wechselnde Preise | 5' | | |
| 5 Reaktion variable Ticketpreise | 4' | | |
| 6 Deep Dive | 5' | | |
| 7 Abschluss | 2' | | |
| **Total** | **30'** | | |

> Läuft der Pretest über 30 Minuten – und das tut er fast immer –, werden **Kann-Fragen
> gestrichen, nicht schneller gesprochen.**

## Gezielt prüfen

- [ ] Fällt vor Block 5 irgendwo das Wort „dynamisch", „fair" oder „Preisdifferenzierung"?
- [ ] Sind alle Fragen offen formuliert (keine Ja/Nein-Antwort möglich)?
- [ ] Ist jede Frage in einem Atemzug verständlich – ohne Nachsatz zur Erklärung?
- [ ] Funktioniert der Übergang von Block 4 zu Block 5 ohne Bruch?
- [ ] Steht der Deep Dive sicher bei 10:38, auch wenn Block 2 überzieht?
- [ ] Weiss der Timekeeper, wie er still signalisiert?

## Feedback der Pretest-Person

1. Welche Frage war unklar?
2. Wo hattest du das Gefühl, es wird eine bestimmte Antwort erwartet?
3. Worüber hättest du gern erzählt, wonach nicht gefragt wurde?
